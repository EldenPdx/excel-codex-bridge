From repo root: `python3 -m venv .venv`; `.venv/bin/pip install .` installs the package and `excel-sub2api` entrypoint. SUB2API deployment: `.venv/bin/excel-sub2api init-secrets packaging/sub2api/secrets`; set `SUB2API_NETWORK` in `packaging/sub2api/.env`; run `docker compose -f packaging/sub2api/compose.yaml config --quiet` then `docker compose -f packaging/sub2api/compose.yaml up -d --build`. Test command: `python -m pytest -q`.
