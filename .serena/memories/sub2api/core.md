Optional sidecar in `packaging/sub2api/compose.yaml`, separate from SUB2API source and database. Uses existing external Docker network named by `SUB2API_NETWORK`; no published host port. It keeps one imported Excel/Codex session in memory per instance. Session import happens only via `excel-sub2api push-session --ssh ...`, which SSHes to the host and executes a container-local management request. Admin endpoint requires loopback and a distinct admin key; do not proxy it. SUB2API upstream account uses `http://excel-sub2api:8000/v1`, the sidecar API key, OpenAI passthrough, and identity model mapping. Full procedure: `docs/sub2api.md`.
